# Janset Genel — portfolio site

This is a no-build static website: plain HTML and CSS, designed from the attached UXfolio screenshot. It is ready to host free on GitHub Pages from a public repository.

## Preview locally

Open `index.html` in a browser. No install or build step is needed.

## Publish free with GitHub Pages

1. Create a **public** GitHub repository. For a personal site URL like `yourname.github.io`, name it `yourname.github.io` (replace `yourname` with your GitHub username).
2. Upload `index.html`, `styles.css`, and this README to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub will show the published URL in the Pages settings. It may take a few minutes to appear.

GitHub Pages is free for public repositories. The repository contents will be public too, so keep private information and confidential work out of it. A custom domain is optional and costs money to register; the included `github.io` address is free.
